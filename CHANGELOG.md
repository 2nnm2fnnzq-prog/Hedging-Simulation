# Changelog

## 1.0.0 — 2026-09-24

Initial public release of the completed hedging simulation study.

- Preserves the scientific implementation, frozen version-2 protocol, and compact results for the pilot, main grid, and numerical refinement checks.
- Includes deterministic accounting checks, path and pricing validation, the saved-result audit, and review notebooks.
- Adds release setup instructions, direct dependency pins, MIT licensing, and software citation metadata. The original full environment lock is retained for provenance.
- Excludes raw simulation outputs and local environments; the documented commands regenerate the raw outputs.

Version 1.0.0 is the software release number; version 2.0 identifies the original study protocol. This release contains no new robustness analyses, no additional market regimes, and no adjusted-Heston versus Black–Scholes inferential extension.
